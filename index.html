I am particularly interested in roles where business context and technical analytics intersect — using data not only to describe what happened, but to understand why it happened and support better decisions.

Loan Default Risk Analysis

Analyzed more than 307,000 loan applications to identify borrower characteristics and portfolio segments associated with higher default risk.

Business Question

Which borrower and regional characteristics are associated with higher loan-default risk, and how can lenders use these patterns to differentiate lending terms?

Dataset 307K+ Applications
Default Rate 8.07%
Class Imbalance 11.39 : 1

Approach

Data Cleaning Feature Engineering EDA Risk Segmentation Data Visualization

Key Findings

  • Overall default rate was 8.07%, with a 11.39:1 repayer-to-defaulter imbalance.
  • Applicants in the Region-Rating 3 segment showed an approximately 11% default rate.
  • Applicants with 40+ years of employment showed a default rate below 1%.
  • Findings supported recommendations for differentiated lending terms across higher- and lower-risk segments.
